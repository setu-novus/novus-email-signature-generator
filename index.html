Outlook setup instructions

New Outlook or Outlook on the web

  1. Complete your details and click Copy signature.
  2. Open Outlook and select the Settings gear.
  3. Go to Accounts > Signatures.
  4. Create a new signature and give it a name.
  5. Click in the signature editor and paste using Ctrl + V.
  6. Set it as the default for new messages and replies if required, then save.
If desktop Outlook changes the formatting, try pasting the signature into Outlook on the web. It is often more reliable for HTML signatures.

Classic Outlook for Windows

  1. Complete your details and click Copy signature.
  2. In Outlook go to File > Options > Mail > Signatures.
  3. Create a new signature and give it a name.
  4. Click inside the editor and paste using Ctrl + V.
  5. Choose the signature as the default for new messages and replies if required.
  6. Save your changes.

Outlook for Mac

  1. Complete your details and click Copy signature.
  2. In Outlook go to Outlook > Settings > Signatures.
  3. Create a new signature.
  4. Click inside the editor and paste using Cmd + V.
  5. Set it as the default signature if required.
